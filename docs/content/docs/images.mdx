There are two ways to show an image:

- **Background image**: a 2D image drawn behind the scene. Cameras and lights do not affect it, and it always covers the whole view.
- **Image in the scene**: a texture on a 3D surface, lit and seen through the camera like any other object. To change the textures of a model, see [Materials and textures](/docs/materials#replacing-textures). To show an image on its own, put it on a [plane](#images-on-a-plane).

Images load from PNG, JPEG and KTX2 files, from the same [sources](/docs/models#asset-sources) as models.

## Background images

[`<BackgroundImage>`](/api/components/background-image) draws an image behind the scene of the closest `<FilamentScene>` and fits it to the closest `<FilamentView>`. Use one per scene.

Imperatively, create the material instance yourself and pass it to `engine.createBackground()`, which returns a [`Renderable`](/api/hybrid-objects/renderable): a full-screen triangle drawn before everything else. Fit the image to the view with [`imageFitTransform`](/api/functions/image-fit-transform) whenever the view's size changes.

<ApiTabs>
<Declarative>

```tsx
import { BackgroundImage, Camera, DefaultLight, FilamentScene, FilamentView, Model } from 'react-native-filament'

export function DroneOnPhoto() {
  return (
    <FilamentScene>
      <FilamentView style={{ flex: 1 }}>
        <Camera />
        <DefaultLight />
        <Model source={require('./drone.glb')} transformToUnitCube />
        <BackgroundImage
          source={require('./background.jpg')}
          materialSource={require('./background_image.filamat')}
          resizeMode="cover"
        />
      </FilamentView>
    </FilamentScene>
  )
}
```

</Declarative>
<Imperative>

```tsx
import { Image } from 'react-native'
import { imageFitTransform, runOnRenderThread } from 'react-native-filament'

const photo = Image.resolveAssetSource(require('./background.jpg'))
const backgroundMaterial = Image.resolveAssetSource(require('./background_image.filamat'))

const [image, material] = await Promise.all([
  engine.loadTexture({ uri: photo.uri }, {}),
  engine.loadMaterial({ uri: backgroundMaterial.uri }),
])

const { instance, background } = await runOnRenderThread(engine, () => {
  'worklet'
  const created = material.createInstance()
  created.setTexture('image', image, {})
  created.setIntParameter('showImage', 1)
  created.setFloat3Parameter('backgroundColor', [0, 0, 0])
  const renderable = engine.createBackground(created)
  scene.addEntity(renderable.entity)
  return { instance: created, background: renderable }
})

// `target` is the ViewTarget your view renders into
const resize = target.addOnResizeListener((width, height) => {
  runOnRenderThread(engine, () => {
    'worklet'
    instance.setMat3Parameter('transform', imageFitTransform(image.width, image.height, width, height, 'cover'))
  })
})

// To remove it: resize.remove(); background.dispose()
```

</Imperative>
</ApiTabs>

`background.dispose()` removes the background from every scene and destroys its entity.

### The background material

`materialSource` is a compiled Filament material, a `.filamat` file. A material defines [the visual appearance of a surface](https://google.github.io/filament/Materials.html#overview/coreconcepts): its material model, the parameters you can set, its raster state such as blending and culling, and its vertex and fragment shader code. Materials are how you provide custom shaders.

`<BackgroundImage>` needs a material with a `vertexDomain` of `device` and these parameters, which it sets for you:

| Parameter | Type | |
|---|---|---|
| `image` | `sampler2d` | The image. |
| `transform` | `mat3` | UV transform from `imageFitTransform`. |
| `backgroundColor` | `float3` | Color around the image when it does not fill the view. |
| `showImage` | `int` | `1` to draw the image, `0` for only the color. |

Use `background_image.filamat` from the example app in the [react-native-filament repository](https://github.com/margelo/react-native-filament/tree/main/apps/shared/assets), next to its human-readable definition `background_image.mat`. Compiled materials are `.filamat` files; definitions are `.mat` files that Filament's `matc` compiles.

<Callout type="info" title="Material versions">
A `.filamat` only loads in the Filament version it was compiled for. If you edit `background_image.mat`, compile it with `matc` from Filament 1.78.
</Callout>

### Resize modes

`resizeMode` (default `'contain'`) decides how the image fills the view. `imageFitTransform(imageWidth, imageHeight, width, height, resizeMode)` computes the matching `mat3` for the material's `transform` parameter. It is a worklet, so it runs on the render thread too.

| Mode | |
|---|---|
| `'contain'` | Shows the whole image and fills the rest with `backgroundColor`. |
| `'cover'` | Fills the view and crops the image. |
| `'scale'` | Stretches the image to the view. |

## Images on a plane

To place an image inside the scene, draw it on a plane. `engine.createPlane(options, materialInstance)` creates a horizontal plane centered at the origin and facing +Y, `width` meters along X and `depth` meters along Z, with texture coordinates from 0 to 1 across it. Draw it with an unlit material that samples a texture:

```glsl title="image_plane.mat"
material {
    name : ImagePlane,
    shadingModel : unlit,
    requires : [ uv0 ],
    parameters : [
        { type : sampler2d, name : image }
    ]
}

fragment {
    void material(inout MaterialInputs material) {
        prepareMaterial(material);
        material.baseColor = texture(materialParams_image, getUV0());
    }
}
```

Compile it with Filament 1.78's `matc`, for example `matc -p mobile -a all -o image_plane.filamat image_plane.mat`. Then create the plane, size it to the image's aspect ratio, and turn it upright to face the camera:

<ApiTabs>
<Declarative>

```tsx
import { Image } from 'react-native'
import {
  quaternionFromAxisAngle, useDisposableResource, useEntityInScene, useFilamentContext, useRenderThreadCallback,
} from 'react-native-filament'

const photo = Image.resolveAssetSource(require('./photo.jpg'))
const imagePlane = Image.resolveAssetSource(require('./image_plane.filamat'))

function PhotoPlane() {
  const { engine, scene, transformManager } = useFilamentContext()
  const texture = useDisposableResource(() => engine.loadTexture({ uri: photo.uri }, {}), [engine])
  const material = useDisposableResource(() => engine.loadMaterial({ uri: imagePlane.uri }), [engine])

  const createPlane = useRenderThreadCallback(() => {
    'worklet'
    const instance = material!.createInstance()
    instance.setTexture('image', texture!, {})
    const plane = engine.createPlane({ width: 1, depth: texture!.height / texture!.width }, instance)
    transformManager.setRotation(plane.entity, quaternionFromAxisAngle([1, 0, 0], Math.PI / 2))
    return plane
  }, [engine, material, texture, transformManager])

  const plane = useDisposableResource(
    () => (material == null || texture == null ? undefined : createPlane()),
    [material, texture, createPlane]
  )
  useEntityInScene(scene, plane?.entity)
  return null
}
```

</Declarative>
<Imperative>

```tsx
import { Image } from 'react-native'
import { quaternionFromAxisAngle, runOnRenderThread } from 'react-native-filament'

const photo = Image.resolveAssetSource(require('./photo.jpg'))
const imagePlane = Image.resolveAssetSource(require('./image_plane.filamat'))

const [texture, material] = await Promise.all([
  engine.loadTexture({ uri: photo.uri }, {}),
  engine.loadMaterial({ uri: imagePlane.uri }),
])

const plane = await runOnRenderThread(engine, () => {
  'worklet'
  const instance = material.createInstance()
  instance.setTexture('image', texture, {})
  const created = engine.createPlane({ width: 1, depth: texture.height / texture.width }, instance)
  engine.transformManager.setRotation(created.entity, quaternionFromAxisAngle([1, 0, 0], Math.PI / 2))
  scene.addEntity(created.entity)
  return created
})

// To remove it: plane.dispose()
```

</Imperative>
</ApiTabs>

[`PlaneOptions`](/api/types/plane-options) also take `castShadows` (default `false`) and `receiveShadows` (default `true`). The plane keeps its material instance alive until it is disposed, and `plane.dispose()` removes it from every scene.
