react-native-filament renders 3D scenes in React Native with Google's [Filament](https://google.github.io/filament) renderer. It is built on [Nitro Modules](https://nitro.margelo.com) and renders on its own thread with a native render loop.

## Requirements

- React Native 0.83 with the New Architecture.
- iOS 15.1 or later.
- Android 7 (API 24) or later.
- iOS renders with Metal. Android renders with Vulkan 1.1 where the device supports it and falls back to OpenGL ES 3.0 otherwise. See [Rendering](/docs/rendering#backends) to choose a backend.

## Installation

<Steps>
<Step>

### Install the packages

Install react-native-filament with its two required peers, [Nitro Modules](https://nitro.margelo.com) and [react-native-worklets](https://docs.swmansion.com/react-native-worklets):

```npm
npm i react-native-filament react-native-nitro-modules react-native-worklets
```

[Reanimated](https://docs.swmansion.com/react-native-reanimated) and [Gesture Handler](https://docs.swmansion.com/react-native-gesture-handler) are optional. Every animatable prop accepts a Reanimated `SharedValue`, and [`useOrbitGestures`](/api/hooks/use-orbit-gestures) returns a Gesture Handler gesture.

</Step>
<Step>

### Add the worklets babel plugin

```js title="babel.config.js"
module.exports = {
  presets: ['module:@react-native/babel-preset'],
  plugins: ['react-native-worklets/plugin'],
}
```

If the app uses Reanimated 4, keep `react-native-reanimated/plugin` instead. It already includes the worklets plugin.

</Step>
<Step>

### Install the pods

```sh
cd ios && pod install
```

The first `pod install` and the first Android build download the prebuilt Filament binaries from GitHub, verify their SHA-256 checksums and cache them for every later build.

</Step>
<Step>

### Configure Metro

Let Metro bundle 3D assets next to your code:

```js title="metro.config.js"
const { getDefaultConfig, mergeConfig } = require('@react-native/metro-config')

const defaultConfig = getDefaultConfig(__dirname)

module.exports = mergeConfig(defaultConfig, {
  resolver: {
    assetExts: [...defaultConfig.resolver.assetExts, 'glb', 'ktx', 'filamat'],
  },
})
```

</Step>
</Steps>

<Callout type="info" title="Models are glTF binaries">
Models load from glTF 2.0 binaries (`.glb`). Convert other formats, such as glTF, OBJ or FBX, with Blender or an online converter.
</Callout>

<Callout type="info" title="Building without GitHub access">
Set `RNF_FILAMENT_BASE_URL` to a mirror of the Filament release assets. To use a local copy, set `RNF_FILAMENT_IOS_ARCHIVE` for `pod install` and `RNF_FILAMENT_ARCHIVE` for Gradle. The checksum is verified either way.
</Callout>

Using Expo? See [Expo](/docs/expo).

## Render your first model

A scene needs four things:

- a view to draw into;
- light, otherwise everything is black;
- a model;
- a camera.

<ApiTabs>
<Declarative>

```tsx title="MyScene.tsx"
import { Camera, DefaultLight, FilamentScene, FilamentView, Model } from 'react-native-filament'

export function MyScene() {
  return (
    <FilamentScene>
      <FilamentView style={{ flex: 1 }}>
        <Camera />
        <DefaultLight />
        <Model source={require('./drone.glb')} transformToUnitCube />
      </FilamentView>
    </FilamentScene>
  )
}
```

</Declarative>
<Imperative>

```tsx title="MyScene.tsx"
import React, { useEffect, useState } from 'react'
import { Image } from 'react-native'
import { callback } from 'react-native-nitro-modules'
import { defaultIndirectLightSource, Filament, NativeFilamentView, runOnRenderThread, type FilamentView } from 'react-native-filament'

const drone = Image.resolveAssetSource(require('./drone.glb'))

export function MyScene() {
  const [view, setView] = useState<FilamentView>()

  useEffect(() => {
    if (view == null) return
    const starting = Filament.createEngine({}).then(async (engine) => {
      const [target, model, environment] = await Promise.all([
        engine.createViewTarget(view, {}),
        engine.loadModel({ uri: drone.uri }, {}),
        engine.loadIndirectLight(defaultIndirectLightSource, { intensity: 25_000 }),
      ])
      const { camera, sun } = await runOnRenderThread(engine, () => {
        'worklet'
        const scene = engine.createScene()
        const sun = engine.createDirectionalLight({ castShadows: true })
        scene.setIndirectLight(environment)
        scene.addEntity(sun.entity)
        scene.addModel(model)
        engine.transformManager.transformToUnitCube(model.rootEntity, model.boundingBox)
        const lens = engine.createCamera()
        lens.lookAt([0, 0, 8], [0, 0, 0], [0, 1, 0])
        target.setScene(scene)
        target.setCamera(lens)
        return { camera: lens, sun }
      })
      const resize = target.addOnResizeListener((width, height) => {
        runOnRenderThread(engine, () => {
          'worklet'
          camera.setLensProjection(28, width / height, 0.1, 100)
        })
      })
      // Keep the target and the light: the scene stores only the light's entity.
      return { engine, target, resize, sun }
    })
    return () => {
      starting.then(({ engine, resize }) => {
        resize.remove()
        engine.shutdown()
      })
    }
  }, [view])

  return <NativeFilamentView style={{ flex: 1 }} hybridRef={callback(setView)} />
}
```

</Imperative>
</ApiTabs>

The declarative version uses React components:

- [`<FilamentScene>`](/api/components/filament-scene) creates an Engine, a scene and its camera, and disposes them when it unmounts.
- [`<FilamentView>`](/api/components/filament-view) shows the scene. Components inside it that draw nothing on screen, like `Camera` and `Model`, configure the scene.
- [`<DefaultLight>`](/api/components/default-light) adds the bundled studio environment and a directional light that casts shadows.
- [`<Model>`](/api/components/model) loads a `.glb` file and adds it to the scene.
- [`<Camera>`](/api/components/camera) places the camera at `[0, 0, 8]`, looking at the origin.

The imperative version builds the same scene from the native objects:

- [`Filament.createEngine()`](/api/functions/filament) creates an [`Engine`](/api/hybrid-objects/engine) with its own render thread.
- [`NativeFilamentView`](/api/components/native-filament-view) is the native view. Its `hybridRef` hands you the view, and [`engine.createViewTarget()`](/api/hybrid-objects/engine) renders into it.
- `engine.loadModel()` and `engine.loadIndirectLight()` can be called from any thread. `loadModel()` resolves once every texture and buffer of the model is uploaded.
- [`runOnRenderThread()`](/api/functions/run-on-render-thread) runs a worklet on the Engine's render thread. Methods that touch the scene, such as `createScene()`, `addModel()` and `setScene()`, must run there.
- `engine.shutdown()` destroys everything the Engine created.

Render regular React Native views on top of a `FilamentView` with absolute positioning, not as its children.

You can mix both styles. Inside a `FilamentScene`, [`useFilamentContext()`](/api/hooks/use-filament-context) returns the Engine, scene, camera and managers that the components use.

## How it renders

The scene renders natively on the Engine's render thread. Animations, camera manipulators, SharedValue-driven props and physics run there without JS. By default it renders on every display refresh. With `<FilamentScene renderMode="on-demand">` it renders only after something changed.
