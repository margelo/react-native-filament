The `<Animator />` component plays an animation of the parent `<Model>` or `<ModelInstance>`. Playback runs natively on the render thread through an `AnimationPlayer`, so no JS runs per frame.

```tsx
import { Animator, Model, type AnimationItem } from 'react-native-filament'

<Model source={require('./dancer.glb')}>
  <Animator
    animationIndex={0}
    transitionDuration={0.4} // seconds to cross-fade from the previous animation
    onAnimationsLoaded={(animations: AnimationItem[]) => console.log(animations)}
  />
</Model>
```

| Prop | Default | |
|---|---|---|
| `animationIndex` | `0` | The animation to play. A Reanimated `SharedValue<number>` switches animations from the UI runtime without React renders. |
| `transitionDuration` | `0` | Seconds to blend from the previous animation. |
| `loop` | `true` | |
| `speed` | `1` | Playback rate. |
| `time` | | Holds the animation at this time in seconds instead of playing, for scrubbing. Accepts a SharedValue. |
| `onAnimationsLoaded` | | Called once with `{ index, name, duration }` of each animation. |

Unmount the `<Animator />` to stop playing.

## Controlling playback yourself

`useAnimationPlayer(instance)` returns the native player. Its methods work from any thread, including Reanimated worklets:

```tsx
const player = useAnimationPlayer(instance)
player?.play(2, { loop: false, crossFadeSeconds: 0.3 })
player?.pause()
player?.seek(1.5)
```

For frame-by-frame control, apply animations on the render thread with the instance's `animator`: `applyAnimation(index, seconds)`, `applyCrossFade(...)` and `updateBoneMatrices()`, for example in a `renderCallback`.
