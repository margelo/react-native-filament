## Transform props

`Model`, `ModelInstance`, `EntitySelector` and `DebugBox` take three transform props. Units are physical: one unit is one meter.

```tsx
<Model
  source={require('./drone.glb')}
  translate={[0, -1, 0]}
  rotate={[0, Math.PI / 4, 0]} // radians around X, then Y, then Z
  scale={[2, 2, 2]}
/>
```

The local transform of the object is `translate · rotate · scale`. The props are absolute: changing `scale` from `[2, 2, 2]` to `[3, 3, 3]` gives a scale of 3, and React re-renders, StrictMode and fast refresh never accumulate. Removing every transform prop gives the object back its original transform.

### Fitting into view

`transformToUnitCube` first scales and centers a model so its bounding box fits into a cube from -1 to 1 around the origin; the transform props then apply on top of that:

```tsx
<Model source={require('./drone.glb')} transformToUnitCube scale={[2, 2, 2]} />
```

### Composing transforms

Instances are children of their model, so transforms on a `ModelInstance` apply inside the model's transform. An `EntitySelector` applies its props on top of the selected node's own transform from the glTF file:

```tsx
<Model source={require('./car.glb')} transformToUnitCube instanceCount={2}>
  <ModelInstance index={0} translate={[-150, 0, 0]} />
  <ModelInstance index={1} translate={[150, 0, 0]}>
    <EntitySelector byName="FrontWheel" rotate={[0, 0.3, 0]} />
  </ModelInstance>
</Model>
```

## Animating transforms

Every transform prop accepts a Reanimated `SharedValue<Float3>`. The value goes from Reanimated's UI runtime straight to a native `TransformBinding`, which applies translation, rotation and scale together at the start of the next frame, with no JS thread work and no React render:

```tsx
import { Easing, useDerivedValue, useSharedValue, withRepeat, withTiming } from 'react-native-reanimated'

function SpinningDrone() {
  const angle = useSharedValue(0)
  const rotate = useDerivedValue<Float3>(() => [0, angle.value, 0])

  useEffect(() => {
    angle.value = withRepeat(withTiming(2 * Math.PI, { duration: 4000, easing: Easing.linear }), -1)
  }, [angle])

  return <Model source={require('./drone.glb')} transformToUnitCube rotate={rotate} />
}
```

Updating transform props through React state also works, but each change re-renders the component; use SharedValues for anything that changes every frame.

## Bindings

For full control, bind an entity's transform yourself. `useTransformBinding(entity)` returns a binding whose setters work from any thread, for example from a `renderCallback` on the render thread:

```tsx
const model = useModel(require('./drone.glb'))
const binding = useTransformBinding(model.state === 'loaded' ? model.rootEntity : undefined)

const renderCallback = useCallback(
  ({ elapsedSeconds }: FrameInfo) => {
    'worklet'
    const [x, y, z, w] = quaternionFromAxisAngle([0, 1, 0], elapsedSeconds)
    binding?.setRotation(x, y, z, w)
  },
  [binding]
)
```

`setBase(matrix)` sets a transform applied before the others, such as `unitCubeTransform(model.boundingBox)`.

## The transform manager

On the render thread, `TransformManager` reads and writes local and world transforms directly. Matrices are column-major `Mat4` arrays; quaternions are `[x, y, z, w]`:

```tsx
await runOnRenderThread(engine, () => {
  'worklet'
  const tm = engine.transformManager
  tm.setTranslation(entity, [0, 1, 0])
  tm.setRotation(entity, quaternionFromAxisAngle([0, 1, 0], Math.PI / 2))
  const world = tm.getWorldTransform(entity)
})
```
