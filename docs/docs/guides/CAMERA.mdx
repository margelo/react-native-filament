## The `<Camera />` components

Your 3D scene needs to be projected to a 2D surface, your view. The camera is the "eye" through which you're looking
in the 3D space and which determines how the 3D scene is projected to the 2D surface.

Each `FilamentScene` has one camera, which every `FilamentView` of the scene renders through. The `<Camera />` component configures its perspective lens and its pose:

- `cameraPosition`: where the camera is (default `[0, 0, 8]`);
- `cameraTarget`: the point it looks at (default `[0, 0, 0]`);
- `cameraUp`: its up direction (default `[0, 1, 0]`).

```tsx
import { Camera } from 'react-native-filament'

<Camera cameraPosition={[0, 1, 10]} cameraTarget={[0, 0, 0]} />
```

Each pose prop also accepts a Reanimated `SharedValue<Float3>`, which moves the camera without React renders:

```tsx
const position = useDerivedValue<Float3>(() => [Math.sin(angle.value) * 8, 1, Math.cos(angle.value) * 8])
<Camera cameraPosition={position} />
```

For orthographic projections or exposure, use the native camera from `useFilamentContext().camera` on the render thread: `setOrthographicProjection()`, `setProjection()` and `setExposure()`.

### Controlling the projection matrix

The camera coordinate system defines the *view space*. The camera points towards its -z axis
and is oriented such that its top side is in the direction of +y, and its right side in the
direction of +x.

There are three parameters that control the projection matrix:

#### `near` plane

- The closest distance from the camera at which objects will be rendered
- Objects closer to the camera than the near plane are clipped and not displayed
- Default is `0.1m`

<details>
    <summary>Impact of the `near` plane on the level of detail / performance.</summary>

The `near` plane greatly affects the depth buffer resolution (the level of detail). For performance reasons, it is recommended to keep the near plane as far as possible (default is `0.1m`).
The table below shows how the precision drops for various `near` plane values (smaller values are better).

 | near (m) | 1 m    | 10 m   | 100 m  | 1 Km   |
 |----------|--------|--------|--------|--------|
 | 0.001    | 7.2e-5 | 0.0043 | 0.4624 | 48.58  |
 | 0.01     | 6.9e-6 | 0.0001 | 0.0430 | 4.62   |
 | 0.1      | 3.6e-7 | 7.0e-5 | 0.0072 | 0.43   |
 | 1.0      | 0      | 3.8e-6 | 0.0007 | 0.07   |
 
 </details>

#### `far` plane

- The farthest distance from the camera at which objects will be rendered
- Objects farther from the camera than the far plane are clipped and not displayed
- Default is `100m`

#### `focalLengthInMillimeters` and `aspect`

The lens's focal length defaults to `28` mm. The aspect ratio follows the size of the closest `FilamentView`; set `aspect` when there is no view, for example for a `useRecorder` video.

The camera can follow a [`CameraManipulator`](../api/interfaces/CameraManipulator), which turns gestures into orbiting, panning and zooming. It runs natively: gestures queue commands from Reanimated's UI runtime and the render thread applies them each frame, with no JS per frame.

`useOrbitGestures(manipulator)` builds the Gesture Handler gesture: one-finger pan orbits, pinch zooms and a double tap returns home.

```tsx
import { GestureDetector } from 'react-native-gesture-handler'
import { Camera, FilamentView, useCameraManipulator, useOrbitGestures, type CameraManipulator } from 'react-native-filament'

function OrbitView({ manipulator }: { manipulator: CameraManipulator }) {
  const gesture = useOrbitGestures(manipulator)
  return (
    <GestureDetector gesture={gesture}>
      <FilamentView style={{ flex: 1 }}>
        <Camera cameraManipulator={manipulator} />
        {/* lights and models */}
      </FilamentView>
    </GestureDetector>
  )
}

function Scene() {
  const manipulator = useCameraManipulator({ homePosition: [0, 0, 8], targetPosition: [0, 0, 0], orbitSpeed: 0.003 })
  return manipulator == null ? null : <OrbitView manipulator={manipulator} />
}
```

`Camera` sizes the manipulator's viewport to its view. For custom gestures, call `grabBegin`, `grabUpdate`, `grabEnd`, `scroll` and `jumpToHome` from any thread.
