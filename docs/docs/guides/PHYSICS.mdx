Physics uses [Bullet](https://github.com/bulletphysics/bullet3), compiled into react-native-filament. A physics world belongs to an Engine and steps itself natively with the Engine's frames. Bodies move the entities they are bound to, so a falling object needs no JS per frame.

## Hooks

| Hook | Creates |
|---|---|
| `useWorld(options)` | A world. `gravity` defaults to `[0, -9.81, 0]`; `autoStep: false` lets you call `world.step(seconds)` yourself. |
| `useBoxShape(world, halfExtent)` | A box. |
| `useSphereShape(world, radius)` | A sphere. |
| `useCylinderShape(world, halfExtent, axis)` | A cylinder along `'x'`, `'y'` or `'z'`. |
| `useStaticPlaneShape(world, normal, constant)` | An infinite plane, for static floors. |
| `useRigidBody(world, options)` | A body with `shape`, `mass` (0 for static bodies), `position`, `rotation`, `friction`, `restitution`, damping, an `id` and an optional `entity` to move. |

Each hook returns `undefined` until its object exists and disposes it on unmount. Disposing a world disposes its bodies.

## Example: falling coins

```tsx
import { useMemo } from 'react'
import {
  Camera,
  DefaultLight,
  FilamentView,
  useCylinderShape,
  useModel,
  useRigidBody,
  useStaticPlaneShape,
  useWorld,
  type CollisionShape,
  type Model,
  type PhysicsWorld,
} from 'react-native-filament'

function Coin({ world, model, shape }: { world: PhysicsWorld; model: Model; shape: CollisionShape | undefined }) {
  const entity = useMemo(() => model.getInstance(0).rootEntity, [model])
  useRigidBody(world, shape == null ? undefined : { shape, mass: 1, position: [0, 3, 0], entity, id: 'coin' })
  return null
}

function Coins() {
  const world = useWorld({ gravity: [0, -9, 0] })
  const coin = useModel(require('./coin.glb'))
  const floor = useStaticPlaneShape(world, [0, 1, 0], -1.5)
  useRigidBody(world, floor == null ? undefined : { shape: floor, mass: 0, id: 'floor' })
  const [x, y, z] = coin.state === 'loaded' ? coin.boundingBox.halfExtent : [1, 1, 1]
  const shape = useCylinderShape(world, [x, y, z], 'y')

  return (
    <FilamentView style={{ flex: 1 }}>
      <Camera />
      <DefaultLight />
      {world != null && coin.state === 'loaded' && <Coin world={world} model={coin.model} shape={shape} />}
    </FilamentView>
  )
}
```

A bound entity takes its body's translation and rotation every step and keeps its own scale.

## Collisions

Listen for contacts on the render thread. Events arrive batched per step, as `began` and `ended` pairs between bodies; return `false` to stop listening:

```tsx
useRenderThreadEffect(() => {
  'worklet'
  if (world == null) return
  const subscription = world.addOnCollisionListener((events) => {
    const landed = events.some((event) => event.kind === 'began' && [event.bodyA.id, event.bodyB.id].includes('floor'))
    if (landed) scheduleOnRN(onLanded)
    return !landed
  })
  return () => subscription.remove()
}, [world, onLanded])
```

## Bodies at runtime

On the render thread, bodies expose `linearVelocity`, `angularVelocity`, `activationState`, `friction`, `restitution`, `applyCentralImpulse()`, `setDamping()` and `setTransform()`. See the [Bullet user manual](https://github.com/bulletphysics/bullet3/blob/master/docs/Bullet_User_Manual.pdf) for the concepts.
